    Class BalancedThreeStackMachine

    A object for simulate the balanced three-stack machine.

    Remarks

    Every rule replaces finite prefixes of three stacks while preserving the sum of their lengths. If every stack letter is chosen uniformly at random, stacks starting with prefixes of total length n occur with probability |letters|^(-n), so this balance means that every rule maps the configurations it applies to onto configurations of exactly the same probability: no rule compresses or expands the configuration space. The families of rule sources and of rule targets are each required to be pairwise separated, so the machine is deterministic and each step is injective. The machine stops when no rule is applicable.

    See

    OpenAI. Incompressible Box Transport and Finite Computation. preprint, 2026. (Section 4)

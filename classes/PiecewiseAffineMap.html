    Class PiecewiseAffineMap

    A object for simulate the piecewise affine map, which repeatedly applies a map defined on finitely many boxes.

    Remarks

    Each step finds the piece whose source box contains the current point and replaces the point with its image. The source boxes are required to be pairwise disjoint, so that the map is well-defined. The target boxes may overlap each other and the source boxes; injectivity and volume preservation are properties of particular constructions (e.g. BalancedThreeStackMachineToPiecewiseAffineMapTransformElement), not of this model. The map stops when the point is in no source box. Points are exact rationals, so the simulation has no rounding error.

    See

    • OpenAI. Incompressible Box Transport and Finite Computation. preprint, 2026. (Section 3, Theorem 3.4)
    • C. Moore. Generalized shifts: unpredictability and undecidability in dynamical systems. Nonlinearity 4(2):199–230, 1991.
